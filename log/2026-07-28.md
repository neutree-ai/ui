## 1. Cluster Edit 表单对齐

Commit:

```text
3411230 feat: align cluster edit form and disabled field states
```

更新内容：

- 将 Edit Cluster 页面向 Create Cluster 的表单结构对齐。
- 减少卡片化分组，改为更统一的 section-based 表单布局。
- 统一以下禁用态控件的视觉样式：
  - Input
  - Select
  - Textarea
  - Combobox
- 统一这些控件在禁用态下的 cursor 行为。
- 恢复可编辑表单项 focus 时的蓝色半透明 outline。

## 2. 表单 section 结构稳定化

Commit:

```text
768a4a0 feat: stabilize cluster form section layout
```

更新内容：

- 新增共享组件 `FormSectionStack`。
- 将 section 之间的分割线交给父级容器统一管理。
- 减少对子组件 DOM 层级的隐式依赖，例如 `:first-child`。
- 修复由于额外 wrapper 导致 section 分割线丢失的问题。
- 更新 Cluster Create / Edit 表单，使其使用更稳定的 section stack 结构。

设计原因：

- section 间距和分割线应该由布局容器统一控制。
- 子 section 不应该依赖自己是否是第一个子元素来决定样式。
- 这样可以降低后续表单中条件渲染、字段包裹、动态分组导致样式异常的风险。
